# Prioritas Untuk Draft Pitching

Karena halaman ini digunakan sebagai **draft untuk pitching calon
customer**, fokus utama adalah membuat bisnis dapat membayangkan website
mereka.

Prioritaskan:

1.  **Hero yang menarik**
2.  **Mini Catalog 6--8 produk**
3.  **Gallery hasil karya**
4.  **Review / social proof**
5.  **CTA WhatsApp yang jelas**

Tidak perlu membuat sistem e-commerce, database produk, checkout, atau
fitur kompleks.

Tujuan draft:

> **Membuat owner berpikir: "Kalau bisnis saya punya website seperti
> ini, ternyata bagus juga."**

Setelah owner tertarik, barulah gali detail produk, harga, layanan,
domain, hosting, dan kebutuhan lainnya.
